English

Vocab Handbook is an offline English vocabulary notebook for iOS. Import words from Excel (.xlsx) or add them by hand; optionally take a photo of a book page, highlight words, and let Google Gemini read them using your own API key (get a key); listen to pronunciation with on-device text-to-speech.

  • "Chưa có Gemini API key" — open AI settings in the app and paste your key.
  • "API key không hợp lệ" — check that the Gemini API is enabled for that key in Google AI Studio.
  • "Đã chạm giới hạn lượt miễn phí" — the free tier has per-minute and per-day limits; wait and retry.
  • Model not found — switch to another Flash model in AI settings.

Tiếng Việt

Vocab Handbook là sổ từ vựng tiếng Anh hoạt động offline trên iOS. Nhập từ từ file Excel (.xlsx) hoặc thêm thủ công; tùy chọn chụp trang sách, tô các từ cần học, để Google Gemini đọc bằng API key của chính bạn (lấy key); nghe phát âm bằng text-to-speech ngay trên máy.

  • "Chưa có Gemini API key" — vào Cài đặt AI trong ứng dụng và dán key.
  • "API key không hợp lệ" — kiểm tra key đã bật Gemini API trong Google AI Studio chưa.
  • "Đã chạm giới hạn lượt miễn phí" — gói miễn phí có giới hạn theo phút và theo ngày, đợi rồi thử lại.
  • Không tìm thấy model — đổi sang model Flash khác trong Cài đặt AI.
